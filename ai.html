AI production assistant

An AI agent inside my editing tools

It does the slow setup so I keep the creative calls.

Multi-camera syncs, brand-accurate animation, and generative workflows eat hours of setup before any creative work starts.

  • Set up an AI agent on the open-source Hermes framework and extended it with skills for the creative software I use.
  • It syncs four-camera shoots to audio, animates brand-accurate designs in After Effects, and builds ComfyUI workflows.
  • It works with DaVinci Resolve, After Effects, Photoshop, Lightroom, and ComfyUI, so its output lands in my project files, ready to edit.
